Access & Roles

Authorization is role-as-email (no role column). The admin flag is email === ADMIN_EMAIL.

Roles (by email)

Admin
admin@insightt.com
  • ✓ Sees the Users menu (frontend).
  • ✓ Creates / edits / deletes users (requireAdmin → 403 otherwise).
  • ✓ Creates users with a temporary password → forced change on first login.
Member
any other user
  • ✗ Users menu hidden in Layout.
  • ✗ Cannot manage users (backend 403).
  • ✓ Can register, log in, and be assigned / shared tasks.

User lifecycle

  1. Admin POST /users → Cognito AdminCreateUser + random temp password → FORCE_CHANGE_PASSWORD.
  2. User signs in with the temp password → InitiateAuth returns NEW_PASSWORD_REQUIRED.
  3. Client calls POST /auth/change-password → RespondToAuthChallenge → session cookies issued.
  4. Self-registration: POST /auth/register → SignUp + admin-confirm-sign-up (auto-confirmed).
  5. GET /auth/me → { id, email, isAdmin }.
